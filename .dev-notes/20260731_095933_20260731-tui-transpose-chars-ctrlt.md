20260731 TUI transpose chars (Ctrl+T)

Added readline transpose-chars (Ctrl+T) to the split-pane curses TUI. _transpose_chars(): with a character on both sides of the caret the pair swaps and the caret advances past them; at the end of the line the last two characters swap and the caret stays at the end; no-op at the start of the line or on a one-character/empty line. Bound to key code 20 in the main loop. Unit tests: 75 TUI tests pass (6 new: mid-word swap + caret advance, at-end swap, at-start no-op, single-char no-op, empty no-op, caret advancement on mid-word). PTY probe /tmp/opencode/tui_pty_transpose.py verified: 'helol' Ctrl+T -> 'hello', again -> 'helol', mid-line Ctrl+T swapped and marker landed at the advanced caret. Docs: docs/SHELL.md keybinding table (Ctrl+T row), docs/ROADMAP.md CLI bullet.
