20260731 TUI kill ring + yank (Ctrl+Y)

Added readline-style kill ring to the split-pane curses TUI. Ctrl+K/U/W now push killed text into a capped ring (10 entries); Ctrl+Y yanks the newest kill, repeating cycles to older entries (yank-pop). A push or an edit to the line between yanks resets the cycle. Also added a search-failed indicator: a no-match reverse/forward query shows 'failed reverse-i-search'/'failed forward-i-search' in the status bar. Unit tests: 54 TUI tests pass (10 new: ring push for K/U/W, yank insert, repeat cycle, empty ring noop, fresh-start after edit, ring cap, ring reset on kill, delete-at-caret not in ring, failed flag set/cleared/empty-query). PTY probe /tmp/opencode/tui_pty_yank.py verified: typed line, Ctrl+K killed, Ctrl+Y restored, Ctrl+W deleted word, Ctrl+Y re-yanked it, Ctrl+Y cycled to the older kill.
