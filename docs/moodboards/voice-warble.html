Voice Warble — calm line, blooms on voice

The center-stage visual for the voice conversation page: an organic aura behind the hero orb and a single fine wave beneath it — simple and clean at rest, blooming into seven echoing traces only while a voice is actually speaking.

CENTER STAGE ONLY line → bloom on voice css-vars + rAF no readouts mic-only signal reduced-motion honored variant 2 · rings — cut A spine · B strokes · C ribbon — cut

Idea

Your voice is analyzed once — intensity, pitch, timbre — and published as CSS variables on the center-stage wrapper. At rest the page shows almost nothing: a soft aura and one fine line, drifting slowly. While you speak, the line blooms — six more traces unfurl beneath it, each rendering the same waveform a few frames behind its neighbor, so the stack warbles as one organism and motion travels down the chain. When you stop, it exhales back to the single line. No numbers on screen; the motion is the readout.

mic → AnalyserNode (already running) features → intensity · pitch Hz · timbre centroid channel → featuresRef → rAF → CSS vars rest → aura + one slow line bloom → 7 traces, delay stagger = the echo

Signal mapping

Voice qualityDerived howDrives
Intensity (loudness) RMS of time-domain buffer, smoothed aura scale/opacity · trace scaleY · orb corona — swell on loudness
Pitch (fundamental) autocorrelation over fftSize 1024 time-domain window → Hz flow duration calc(360000ms / pitch) — ~2.4 s/period at 150 Hz while bloomed; the resting line runs at half speed for calm
Timbre (brightness) spectral centroid of frequency bins, normalized trace gradient lightness + opacity falloff — bright, dense voice = crisp high traces; soft voice = dim, spread
Voice presence intensity sustained above floor, with hold + hysteresis --bloom 0↔1 — blooms fast (~150 ms) while you speak, settles slowly (~2 s) back to the line; brief pauses don't flicker it
State the existing VoiceState machine color from VOICE_STATE_TONE + the matrix below

State matrix

idle The resting look: aura at low opacity, one slow line. Honest "not listening" (AI UX rule: never look live when the mic is off).
listening Line present, ready — blooms to the full 7-trace echo the moment voice activity crosses the floor.
processing Exhales back to the single line, drifting slowly; aura eases toward the warning tone.
speaking Resting line with a gentle pulse (mic-only signal: browser TTS output cannot be captured, so the AI voice cannot drive the wave).
error Flatline — animation stops, aura holds a dim destructive tint. The StatusBanner carries the message.

Motion spec

Resting lineone trace, half-speed flow — calc((360000ms + (1 - bloom) * 360000ms) / pitch), calm ~4.8 s/period at 150 Hz
Bloomsix leaf traces scale + fade in over 520 ms (ease-out), unfurl stagger calc(var(--i) * 70ms) — the stack opens downward like a fan
Settleslower decay back to the single line (~2 s) with hysteresis — pauses in speech don't flicker the bloom
Echo staggeranimation-delay: calc(var(--i) * -0.16s), i = 1…6 — the signature "backing each other"
Intensity response90–120 ms linear transitions on scale/opacity; vars written per-frame by the component's own rAF loop
Reduced motion@media (prefers-reduced-motion: reduce) — all animation off, static composition retained (header status text carries state)
React re-rendersnone at frame rate — discrete state changes only, same as the orb today
